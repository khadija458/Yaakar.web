Guide d'Utilisation

  • Vérification : Entrez le code du ticket pour savoir en temps réel s'il est authentique ou non.
  • Sécurité des codes : Chaque code est unique dans la base de données.
  • Protection Admin : La création, modification et suppression nécessitent une session administrateur active.
  • Identifiants initiaux : Utilisateur admin / Mot de passe admin1234.
